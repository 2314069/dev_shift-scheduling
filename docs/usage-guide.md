# シフトすけっと 使い方ガイド

> 最終更新: 2026-05-05 | 対象バージョン: Phase 1-8 完了時点

このガイドは **店長・シフト管理者** 向けの操作説明書です。技術的な背景については [技術ガイド](technical-guide.md) を、個人情報の取り扱いについては [個人情報保護リファレンス](privacy-considerations.md) を参照してください。

> **表記について**: 画面上は「店舗」と表示しますが、内部コード・API では `organization` という名称を使っています。どちらも同じものを指しています。

---

## はじめに

**シフトすけっと** は、小規模店舗向けの自動シフト作成ツールです。スタッフの希望や制約を入力すると、数理最適化（= コンピューターが計算してシフトを自動割り当て）によりシフト表を自動生成します。

### 主な特徴

- **希望入力から自動割り当てまで一貫して管理** — スタッフが希望を入力し、管理者が最適化を実行するだけでシフト表が完成します
- **柔軟な制約設定** — 連勤上限・必要人数・スキル要件・役割別人数など細かい条件を設定できます
- **手動微調整もできる** — 自動生成後のシフト表を手動で直すことも可能です
- **スタッフ向け公開機能** — 完成したシフト表をスタッフが専用URLで閲覧できます

### 必要な準備

| 項目 | 内容 |
|------|------|
| 端末 | PC（Windows / Mac）推奨。スマートフォンでも利用可能 |
| ブラウザ | Chrome / Firefox / Safari / Edge の最新版 |
| メールアドレス | Magic Link（メールで届くログインリンク）を受け取れるメールアドレス |

## 1. 初めて使う方へ

### 1.1 サインイン（Magic Link）

シフトすけっとはパスワード不要の **Magic Link 認証** を採用しています。

1. ブラウザで `https://shift-suketto.jp` にアクセスします
2. メールアドレスを入力して **「Magic Link を送信」** をクリックします
3. 数分以内に届くメールのリンクをクリックするとサインイン完了です

[スクリーンショット: サインイン画面 `/signin`]

> **リンクが届かない場合**: 迷惑メールフォルダを確認してください。それでも届かない場合は、メールアドレスを確認して再度送信してください（[5.2 ログインできない](#52-ログインできない--magic-link-再送)）。

---

### 1.2 店舗を作成する

初回サインイン後、店舗が未作成の場合は自動的に店舗作成画面（`/onboarding`）に案内されます。

1. **店舗名** を入力します（例: 渋谷カフェ 本店）
2. **「お店を登録して始める」** をクリックします
3. 店舗が作成され、初期設定ガイド画面（`/onboarding/getting-started`）に進みます

[スクリーンショット: 店舗作成画面 `/onboarding`]

> 店舗は1アカウントに1つ作成できます。

---

### 1.3 初期データを投入する（4ステップ）

初期設定ガイド画面（`/onboarding/getting-started`）にチェックリストが表示されます。以下の順に設定を進めてください。

| # | やること | 移動先 | 必須 / 任意 |
|---|---------|--------|------------|
| 1 | スタッフを登録する | 設定 (`/settings`) | **必須** |
| 2 | シフト枠を登録する | 設定 (`/settings`) | **必須** |
| 3 | 必要人数を設定する | 設定 (`/settings`) | 任意（設定しないと最適化条件が緩くなります） |
| 4 | 最初のシフト期間を作成する | シフト表 (`/schedule`) | — |

スタッフとシフト枠の両方が登録されると、最適化（= 自動でシフト割当）の実行が可能になります。

[スクリーンショット: 初期設定ガイド画面 `/onboarding/getting-started`]

詳細な設定手順は [2. 日常運用](#2-日常運用) を参照してください。シフト表画面には、未設定の項目がある場合にヒントカード（`OnboardingHintCard`）が表示されます。

---

## 2. 日常運用

シフト作成の基本的な流れは以下のとおりです。

```
1. 設定（スタッフ・シフト枠・必要人数を登録）
       ↓
2. スケジュール期間を作成する
       ↓
3. スタッフが希望を入力する
       ↓
4. 最適化を実行してシフト表を自動生成する
       ↓
5. 必要に応じて手動で微調整する
       ↓
6. シフト表を公開する
```

---

### 2.1 スタッフ管理

画面上部のナビゲーションから **「設定」** をクリックし、「スタッフ管理」セクションを開きます。

[スクリーンショット: 設定画面 `/settings` のスタッフ管理セクション]

#### スタッフを追加する

1. **「追加」** ボタンをクリック
2. 以下の情報を入力します

| 項目 | 説明 | 例 |
|------|------|---|
| 名前 | スタッフの氏名 | 田中 太郎 |
| 役割 | 「リーダー」「一般」など | リーダー |
| 最大勤務日数/週 | 週あたりの勤務上限（デフォルト: 5） | 3 |

3. **「保存」** をクリック

登録済みスタッフは一覧に表示されます。**「編集」** で変更、**「削除」** で削除できます。

---

### 2.2 シフト枠の設定

設定画面（`/settings`）の「シフト枠管理」セクションを開きます。

#### シフト枠を追加する

1. **「追加」** ボタンをクリック
2. 以下の情報を入力します

| 項目 | 説明 | 例 |
|------|------|---|
| シフト名 | シフトの名称 | 早番、遅番、夜勤 |
| 開始時間 | シフトの開始時刻 | 09:00 |
| 終了時間 | シフトの終了時刻 | 17:00 |

3. **「保存」** をクリック

---

### 2.3 必要人数の設定

設定画面（`/settings`）の「必要人数設定」セクションを開きます。

#### 基本の必要人数を追加する

1. **「追加」** ボタンをクリック
2. 以下の情報を入力します

| 項目 | 説明 | 例 |
|------|------|---|
| シフト枠 | 対象のシフト枠 | 早番 |
| 日種別 | 平日 または 休日 | 平日 |
| 最低人数 | そのシフトに必要な最低人数 | 3 |

3. **「保存」** をクリック

> **例**: 早番が「平日3人、休日2人」必要な場合は2つのレコードを登録します。

役割別の必要人数（「リーダーを1人以上」など）は [3.3 役割別必要人数](#33-役割別必要人数) で設定できます。

---

### 2.4 スタッフからの希望入力

ナビゲーションから **「希望入力」** をクリックします（画面URL: `/staff`）。

[スクリーンショット: 希望入力画面 `/staff`]

#### スタッフの選択

希望入力画面を開くとスタッフ一覧が表示されます。自分の名前をクリックします。

> URLに `?id=スタッフID` を付けて直接アクセスすることもできます（例: `/staff?id=3`）。スタッフへシフト枠URL を伝えると手間が省けます。

#### 希望を入力する

1. 対象の **スケジュール期間** をドロップダウンから選択します
2. カレンダー上の日付をクリックします
3. 表示されるメニューから以下を選択します

| 選択肢 | 意味 | 表示色 |
|--------|------|--------|
| 「希望: 早番」など | その日にそのシフトを希望する | 青 |
| 「出勤不可」 | その日は出勤できない | 赤 |
| 「クリア」 | 入力を取り消す | 灰色 |

4. すべての希望を入力したら **「希望を提出」** をクリックします

---

### 2.5 シフトの自動最適化

ナビゲーションから **「シフト表」** をクリックします（画面URL: `/schedule`）。

[スクリーンショット: シフト表画面 `/schedule` — 最適化前]

#### スケジュール期間の作成

1. **「期間を作成」** エリアに開始日・終了日を入力します（例: 2026-06-01 〜 2026-06-15）
2. **「期間を作成」** をクリックします
3. 作成された期間はドロップダウンに表示されます（ステータス: 「下書き」）

#### 最適化を実行する

1. ドロップダウンから対象の期間を選択します
2. **「最適化実行」** ボタンをクリックします
3. 数秒待つと、シフト表が自動生成されます

[スクリーンショット: シフト表画面 `/schedule` — 最適化後]

#### 最適化で考慮される条件

- 各シフト枠の **必要人数** を満たす
- スタッフの **出勤不可日** を厳守
- **連勤制限**（設定に依存。デフォルト: 6日連続まで）
- スタッフごとの **週あたり勤務上限**
- 1日に1つのシフトのみ割り当て
- **スキル・資格要件**（スキル設定がある場合）
- **逆循環シフト禁止**（例: 夜勤→早番の連続を禁止。設定による）

> **「実行可能なシフトが見つかりませんでした」と表示された場合**: 制約が厳しすぎます。診断パネルで原因を確認してください（[5.1 最適化が失敗する](#51-最適化が失敗する--診断パネルの読み方)）。

---

### 2.6 シフト表の手動編集と公開

#### 手動でシフトを変更する

最適化後のシフト表を確認し、必要に応じて手動で調整できます。

1. シフト表のセルをクリックします
2. ドロップダウンからシフト枠を変更するか、「休み」を選択します
3. 手動編集したセルは **オレンジの枠線** で表示されます

> 手動編集した割り当ては、再度最適化を実行しても保持されます。

#### シフト表を公開する

調整が完了したら:

1. **「公開」** ボタンをクリックします
2. ステータスが「公開済み」に変わります
3. スタッフは「スタッフ向け閲覧」画面（`/view`）から公開されたシフト表を確認できます

> 公開後はシフト表の編集ができなくなります。

#### シフト表の見方

| 表示 | 意味 |
|------|------|
| 色付きセル | シフト割り当てあり（色はシフト枠ごとに異なります） |
| オレンジ枠線 | 手動編集されたセル |
| グレー / `-` | 休み（割り当てなし） |
| 赤背景の列ヘッダー | 土日 |

#### シフト表をCSVでエクスポートする

シフト表画面の **「CSVエクスポート」** ボタンから、シフト表をCSV形式でダウンロードできます。

---

### 2.7 公平性ダッシュボード

シフト表画面（`/schedule`）の **「公平性ダッシュボード」** タブを開くと、スタッフ間の勤務状況の偏りを確認できます。

[スクリーンショット: 公平性ダッシュボード]

| 表示内容 | 説明 |
|---------|------|
| スタッフ別 勤務日数 | 各スタッフの期間内の勤務日数と比較 |
| 希望シフト反映率 | スタッフが希望したシフトがどれだけ割り当てられたか |

---

### 2.8 スタッフ向け閲覧画面（公開後）

公開済みのシフト表は `/view` でスタッフが確認できます。

[スクリーンショット: スタッフ向け閲覧画面 `/view`]

- **読み取り専用**: 閲覧のみで編集はできません
- **行ハイライト**: 自分の名前の行がハイライト表示されます
- スタッフへは `/view` のURLを共有してください

## 3. 設定変更

### 3.1 ソルバー設定（制約スイッチ・業種プリセット）

設定画面（`/settings`）の **「ソルバー設定」** パネルから、最適化エンジンの動作を細かく調整できます。

[スクリーンショット: ソルバー設定パネル]

#### 業種別プリセット

よく使われる業種の制約条件をまとめて適用できます。

| プリセット | 想定業種 | 主な設定内容 |
|-----------|---------|------------|
| 飲食店 | レストラン・カフェ | 連勤制限・逆循環シフト禁止など |
| 小売 | スーパー・コンビニ | シフト間隔・週勤務日数上限など |
| 医療・介護 | クリニック・施設 | 夜勤制限・資格配置要件など |

プリセットを選択すると、対応する制約スイッチが自動的にオン/オフになります。

#### 個別の制約スイッチ

各制約を個別に有効/無効にできます。

| 制約 | 説明 |
|------|------|
| 連勤制限 | 連続勤務日数の上限を設定 |
| 逆循環シフト禁止 | 深夜→早朝などの不利なシフト連続を禁止 |
| 最大勤務日数/週 | 週あたり勤務日数の上限を適用 |

---

### 3.2 スキル要件

設定画面（`/settings`）の **「スキル要件」** セクションから、スタッフのスキル・資格を管理できます。

[スクリーンショット: スキル要件設定画面]

#### スキルの設定手順

1. スタッフに保持スキル（例: 「調理師免許」「レジ操作」）を登録します
2. シフト枠に必要スキルを設定します（例: 「早番は調理師免許が必要」）
3. 最適化時に自動で条件が反映されます

---

### 3.3 役割別必要人数

設定画面（`/settings`）の **「役割別必要人数」** セクションから、役割ごとの配置人数制約を設定できます。

| 項目 | 説明 |
|------|------|
| シフト枠 | 対象のシフト枠 |
| 日種別 | 平日 または 休日 |
| 役割 | 対象の役割（例: リーダー） |
| 最低人数 | その役割の最低配置人数 |

> **例**: 「早番の平日にはリーダーを最低1人配置する」→ シフト枠=早番、日種別=平日、役割=リーダー、最低人数=1 で登録

## 4. アカウント管理

### 4.1 ログアウト

ナビゲーションの **「ログアウト」** をクリックするとサインアウトします。

---

### 4.2 アカウント削除（個人情報削除）

アカウントを削除する場合は `/account/delete` にアクセスしてください。

[スクリーンショット: アカウント削除画面 `/account/delete`]

#### 削除の手順

1. `/account/delete` にアクセスします
2. 確認フレーズ（「削除する」など）を入力フィールドに入力します
3. **「アカウントを削除する」** ボタンが有効になるのを確認します
4. ボタンをクリックします

#### 削除される内容

アカウント削除を実行すると、以下のデータがすべて完全に削除されます（復元不可）。

| 削除されるデータ |
|----------------|
| ユーザーアカウント（メールアドレス含む） |
| 店舗データ（あなたが owner の店舗） |
| スタッフ情報 |
| シフト枠・必要人数設定 |
| スタッフの希望データ |
| シフト表・割り当てデータ |

> **注意**: 削除後の復旧はできません。削除前にシフト表のCSVエクスポートでデータをバックアップすることを推奨します。

個人情報の取り扱い詳細は [個人情報保護リファレンス](privacy-considerations.md) を参照してください。

## 5. トラブルシューティング

### 5.1 最適化が失敗する → 診断パネルの読み方

**「実行可能なシフトが見つかりませんでした」** と表示された場合、シフト表画面の **「診断」** タブを開いてください。

[スクリーンショット: 最適化診断パネル]

診断パネルには以下の情報が表示されます。

| 表示内容 | 確認すべきこと |
|---------|--------------|
| 制約の競合箇所 | どの日・どのシフトで人員が足りないか |
| 改善提案 | 必要人数の見直し、スタッフ追加などの具体的な提案 |

#### よくある原因と対処法

| 原因 | 対処法 |
|------|--------|
| 必要人数に対してスタッフが少ない | 必要人数を減らすか、スタッフを追加する |
| 出勤不可日が多くシフトが埋まらない | 特定の日の必要人数を引き下げる |
| スキル要件を満たすスタッフがいない | スタッフのスキル設定を確認する |
| 連勤制限が厳しすぎる | ソルバー設定で連勤上限を緩和する |

---

### 5.2 ログインできない → Magic Link 再送

Magic Link メールが届かない場合:

1. **迷惑メールフォルダ** を確認します
2. 数分待っても届かない場合、サインイン画面に戻ってメールアドレスを再入力し、**「Magic Link を送信」** をもう一度クリックします
3. それでも届かない場合は、メールアドレスが正しいか確認してください

---

### 5.3 データが消えた / その他の問題

お問い合わせ窓口（Phase 2-3 で整備予定）までご連絡ください。

---

## よくある使い方のパターン

### 月前半・後半に分けて管理する

1. 6/1〜6/15 の期間を作成 → 最適化 → 公開
2. 6/16〜6/30 の期間を作成 → 最適化 → 公開

### 最適化結果が気に入らない場合

1. シフト表を手動で直接修正する
2. または設定（必要人数・スタッフ数・制約スイッチ）を変更して再度最適化を実行する

### スタッフを追加した場合

設定画面でスタッフを追加した後、最適化を再実行すると新しいスタッフも含めて再計算されます。

### スタッフへシフト表を共有する

シフト表を公開した後、`/view` のURLをスタッフに共有してください。スタッフは自分の行がハイライトされたシフト表を閲覧できます。
